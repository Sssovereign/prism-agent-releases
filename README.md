# 棱镜 Prism 发行下载

本仓库仅用于托管 Prism 安装包、签名业务资源包、更新清单与发行说明。产品源码仓保持私有。

[下载当前版本](https://github.com/Sssovereign/prism-agent-releases/releases)

棱镜 Prism 0.0.5-beta

- 独立桌面 App，首次安装无需 Node 或 pnpm。
- 新增应用内更新：检查版本、下载与验签，等待任务空闲后重启本地服务生效，失败恢复原业务版本。
- 日常界面和业务修复使用约 7 MiB 资源包；运行环境、依赖或数据库结构变化使用完整安装包覆盖升级。
- 本版包含陪审员联网核对、智谱搜索余额报错修复，以及 MCP 远程 HTTP 连接支持。

首次从 0.0.4-beta 升级需覆盖安装一次 0.0.5-beta，之后兼容的业务更新可在设置 → 关于棱镜 → 应用内更新完成。账号、模型配置、历史和凭据保存在本机，安装前建议备份。

macOS：Apple Silicon（arm64）；Windows：x64。macOS 使用本地签名，尚未公证；Windows 未配置代码签名，真实 Windows 安装和更新仍待验证。完整安装包自动替换暂未启用；应用内提供官方下载入口。

安装包和资源包包含可提取的编译后 JavaScript。发行物公开下载不表示私有源码仓或 Git 历史已公开，也不新增整个工程的开源许可。第三方许可随安装包保留。
